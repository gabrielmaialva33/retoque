lsfg-vk: the LSFG 3.1 pass structure
====================================

retoque/lsfg/ (LsfgGraph.h, LsfgShaderLibrary.cpp, LsfgFrameGen_Dx12.cpp) and
tools/lsfg-study/derive_ids.py run Lossless Scaling's frame generation from the
user's own lsfg-vk.dll. No lsfg-vk source file is copied. Retoque uses facts
about the pass structure from two lsfg-vk revisions:

  lsfg-vk v1.0.0 (MIT), commit 7113d7d02da9fc9df5cb3b03230d1f7de86f7056
  https://github.com/PancakeTAS/lsfg-vk/tree/v1.0.0
    src/extract/extract.cpp: the chain names alpha[0..3], beta[0..4],
    gamma[0..4], delta[0..9], their performance variants, and mipmaps and
    generate without performance variants.

  lsfg-vk, GPL-3.0-or-later (SPDX headers of each file),
  commit 8b0da2661c6f3473a7fccc8ba643880050e71642
  https://github.com/PancakeTAS/lsfg-vk/tree/8b0da2661c6f3473a7fccc8ba643880050e71642
    lsfg-vk-backend/src/lsfgvk.cpp: chain wiring, pyramid levels, the three
    samplers; src/shaderchains/*.cpp: inputs, outputs, image formats and
    dispatch tiles; src/extraction/shader_registry.cpp: sampled and storage
    image counts per role for quality and performance;
    lsfg-vk-common/src/vulkan/sampler.cpp: sampler filtering and borders.

Both revisions number shaders by Lossless.dll's resource ids. lsfg-vk.dll's
ids, bindings and constant layout come from the user's own DLL, reflected at
run time and by tools/lsfg-study/derive_ids.py. Retoque's epsilon0..4 is
lsfg-vk's delta[5..9].
