# nr-replay-metrics (host)

Run `python3 tests/nr-replay-metrics/run.py`. Standard-library Python only.

Small analytic sequences exercise backward MV scale/UV/jitter, bilinear sampling and depth
rejection; motion-oracle mutations reject zero/swapped/scaled guides and wrong jitter.
Pulse, opposite regional pulse, blur and frozen-output mutations exercise the real judge.
A/A envelopes, reference identity, per-pixel golden thresholds, coverage, absent calibration,
invalid metadata and CLI artifact replacement are checked behaviorally.
Dejittered color ignores recorded jitter while jittered analytic color needs the delta;
embedded jitter is not added twice. Warmup skips preserve A/A eligibility and break pairs.
Repeated trial IDs (including a reference ID) are rejected in creation and consumption of
calibration artifacts, even when manifests differ.
When NumPy is importable, parity tests force both backends and compare all summary/per-frame
metrics within 1e-6 and require identical verdicts, including fractional UV motion, jitter,
sRGB, depth rejection, cuts and one-pixel regions. This comparison skips cleanly without NumPy.
Run it explicitly with `uv run --with numpy python tests/nr-replay-metrics/run.py`.
Warmup metrics are not computed; its last usable frame supplies the first scored pair.
Unpaired disocclusion is null rather than a measured zero.

All imagery is generated by `tests/_support/replay_fixture.py`; calibration repeats here are
synthetic controls, not an NGX noise estimate. No production DLL/model is executed and no
real-game quality is claimed. The [design](../../docs/dlssnr/design/offline-replay.md) defines
which parts need later GPU/recorder validation.
