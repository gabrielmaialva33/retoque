> **For agentic workers:** Use superpowers:subagent-driven-development for implementation and independent review. Follow the project instructions over generic skill defaults; no commit, merge or push is authorized.

**Goal:** Remove unused coarse-history reductions while preserving the current NR image and adaptive decisions.

**Architecture:** Keep existing history buffers and scheduler. Share the acceptance calculation between carry and probe, then move the unchanged coarse dispatch from every model Record to the first Carry that consumes that history.

**Tech Stack:** C++20, D3D12, HLSL/DXIL, Python host runner, MSVC under Wine, offline replay and Cyberpunk benchmark.

## Review Focus

- Adaptive 1 to 2/3/4 recovery uses the most recently recorded history.
- Repeated model-only frames never build a coarse image that will be overwritten unused.
- Fade reads the old history before Record overwrites it; subsequent first carry prepares the new coarse image.
- Refusals, resets, duplicate views, failed/partial models and dimension changes cannot expose stale coarse data.
- Probe acceptance is unchanged for partial rejection and non-finite input, with no residual/coarse dependency.
