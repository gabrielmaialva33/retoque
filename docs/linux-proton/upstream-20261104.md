# OptiScaler upstream integration, 2026-11-04

Merge `optiscaler/master` at `5bf6d19d` (3 commits after `ed5708bb`) onto Retoque `651ef627`, on
`integrate/upstream-20261104`. No conflicts, no submodule moves.

## Why now

- `5bf6d19d` (Vulkan shutdown crash): `NVSDK_NGX_VULKAN_ReleaseFeature` waits on the device the feature was created
  on, `IFeature_Vk::GetDevice()` (`Device`), or for Vulkan-with-D3D12 features `IFeature_VkwDx12::GetDevice()`
  (`VulkanDevice`), instead of the input's global `vkDevice`, and skips the wait when that device is null.
- `d217b093` (DP4a on Vulkan): `VulkanDeviceFeatureState` now copies and enables `shaderIntegerDotProduct`, through
  `VkPhysicalDeviceVulkan13Features` when the request carries it, else through
  `VkPhysicalDeviceShaderIntegerDotProductFeatures` (1.3 without the 1.3 struct, or the KHR extension below 1.3).
  `hkvkCreateInstance` raises the instance to 1.3 when the FG output is DLSS-G, 1.2 for FSR-FG as before.
- `5eb4bfab`: a "Lemon zest" FPS-overlay preset, and the "Afterburner-Like" preset renamed "Afterburner".

## Decisions

- The fork's Vulkan device-creation layer is kept as it was: the version-of-feature-chain rule
  (`ApiVersionOfFeatureChain`), per-thread extension storage and the memory-model device-scope additions sit beside
  the new code without overlap. `VkPhysicalDeviceShaderIntegerDotProductFeatures` was already in the fork's chain
  type table (`retoque/hooks/Vulkan_DeviceCreateChainTypes.h`), so the copied chain keeps its size.
- The upstream branches keep the spec's rule that a promoted struct is not chained beside
  `VkPhysicalDeviceVulkan13Features`: the 1.3-struct branch returns before the KHR struct is added.
- NR's Vulkan feature lifetime (`DlssNrFeature_Vk.cpp`, under `g_vkMutex`) does not go through this wait and is
  unchanged. A feature whose `Init` never ran has a null device and now waits on nothing; it also never recorded
  work on a device.
- The 1.3 raise is limited to FG output DLSS-G on a Vulkan game; the fork's LSFG takeover of FSR-FG and the D3D12
  routes are not affected.

## Verification boundaries

- Release build, host tier and clang-format 22 on the merged lines: see the merge commit message for the run.
- Not run: wine tier, GPU, any Vulkan game. The shutdown fix (a Vulkan game closing with an OptiScaler upscaler
  feature live) and the DP4a/1.3 path (XeSS DP4a, DLSS-G output on Vulkan) are untested at runtime here.
